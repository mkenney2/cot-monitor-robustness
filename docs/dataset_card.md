## What this is

All artifacts needed to reproduce **cot-monitor-robustness**
(github.com/mkenney2/cot-monitor-robustness): a study of text-level vs
activation-level monitoring of chain-of-thought under adversarial rewrites,
on a silent hint-use task with Qwen 3.6 27B.

**Why gated:** the question pool includes GPQA-diamond items. GPQA is
distributed gated with a request that its text never appear on the open
internet (training-data contamination). This dataset inherits that
restriction; everything else about it is open. The MMLU-derived majority of
items carries no such restriction — gating the whole dataset is simply the
conservative packaging.

This dataset includes text generated by Qwen 3.6 27B (policy rollouts),
Claude Opus 4.5 via OpenRouter (judge scores, verbalization labels), and
Kimi K3 via OpenRouter (adversarial CoT rewrites).

## Contents

### `core/` (~a few hundred MB — the notebook default)

| File | One row per | Contents |
|---|---|---|
| `hinted_items.jsonl` | item | question block, hint text/type/letter, correct answer |
| `labels.parquet` | item | class (POS / NEG-inert / NEG-clean), canonical CoT, vote counts, verbalization labels |
| `attacked_transcripts.parquet` | item × attack | rewritten CoT (paraphrase / launder / recruit), re-verification survival |
| `scores_clean.parquet` | transcript × arm | suspicion score from each of the monitor arms, train/test split |
| `scores_attacked.parquet` | transcript × arm × attack | frozen-monitor scores on attacked transcripts |
| `judge_outputs.parquet` | transcript × sample | raw judge probabilities + one-sentence justifications |
| `pooled_features.parquet` | transcript | mean-pool + last-token residual vectors, layers 16/32/48 |
| `pooled_features_attacked.parquet` | transcript × attack | same, over rewritten transcripts |
| `probe_model.joblib` | — | the frozen primary probe (StandardScaler + logistic regression, layer 48) |
| `results/*.json` | — | every published number: AUCs + CIs, degradation matrix, failure correlation, controls |
| `review/*.md` | — | the seeded random samples used for human label-checking |

### `activations-full/` (~17 GB clean + ~? GB attacked, optional)

Per-token fp16 residual streams (`{qid}.npz` / `{qid}__{attack}.npz`):
CoT-span activations at layers 16/32/48 plus token ids. Needed only to
reproduce the J-Lens arm and token-level analyses; the probe and all
headline figures need only `pooled_features*.parquet`.
